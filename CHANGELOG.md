# Changelog

Missing builds and release dates have not been inferred.

## Updating this changelog

For future releases, add user-facing changes under **Unreleased**. When publishing, move those changes into a version/build entry with the actual release date, and update the matching Fastlane `<build-number>.txt` file. `default.txt` is fallback store text, not a separate release.
